# Travel

Personal travel atlas with map and card views resolved at build time from deduped, coverage-validated JSON collections of journeys, starred places, categories, and regions. Features clustered category markers, detail popups, visited-region overlays, search with category, journey, and starred filters, cross-view navigation, keyboard shortcuts, persisted filters and camera, and a self-hosted worldwide vector basemap with street-level coverage regions, geography-aware zoom caps, and no external APIs. Built with Astro, React, TypeScript, and Tailwind CSS. Deployed on Netlify.
