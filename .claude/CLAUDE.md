# Travel

Personal travel atlas with map and card views of markers gathered from journeys, starred favorites, categories, and visited regions backed by content collections. Features clustered category markers with detail popups, visited-region overlays, search with category, journey, and starred filters, cross-view navigation, keyboard shortcuts, persisted filters and camera, and a self-hosted worldwide vector basemap with street-level coverage regions and geography-aware zoom caps. Built with Astro, React, TypeScript, Tailwind CSS, and MapLibre GL. Deployed on Netlify.
